# OATHBOUND

2D CRPG в духе Ultima: остров, Вестмер, Двор клятвы, пиратский киль.

## Где править контент

Главный файл мира и строек:

- [`src/game/oathbound.json`](src/game/oathbound.json) — участки, варианты построек, рецепты, метки карты
- копия для чтения: `public/content/oathbound.json`

Движок и карты:

- `src/game/world.ts` — оверворлд и интерьеры
- `src/game/content.ts` — предметы, NPC, диалоги
- `src/game/engine.ts` — бой, крафт, стройка
- `src/game/heroes.ts` — герои и таланты
- `src/components/oathbound.tsx` — HUD, карта, диалоги

## Запуск

```bash
npm install
npm run dev
```

## Что уже есть

- Мир 80×62, карта на **M**
- 6 участков с 3 вариантами построек, включая островную гавань (E или ЛКМ на подсвеченной площадке)
- Крафт в кузнице двора или избе травника
- Сбор одним кликом: лес → дерево, топь → трава; на острове → плавник, ламинария и панцирь
- Большой вулканический остров: полоса отлива, базальтовый хребет, туман, крабы и приливный камень
- Живой 75-секундный цикл прилива: берег меняет цвет, а ресурсы возвращаются с новым отливом
- Приливный грот с отдельной картой, боссом и экранной полосой здоровья
- Островные гарпун, штормовой плащ и панцирная броня меняют модель героя после экипировки
- Уникальный Венец отлива открывает слот шлема и добавляет ещё один визуальный слой героя
- Диалоги с портретами, плащи-личины, корабль Рина
- Автосохранение прогресса в браузере, **Esc** — пауза, кнопка «Продолжить» в главном меню

Исследовательские опоры острова описаны в [`docs/island-design.md`](docs/island-design.md), архитектурный путь к совместной игре — в [`docs/multiplayer-roadmap.md`](docs/multiplayer-roadmap.md).

## Графика

Оставить гибрид: **пиксель 32×32 на карте + писаные портреты в разговоре**.  
Это язык Ultima / раннего Diablo. Полностью «прорисовать» модельки из меню как маслом и воткнуть их в тайл — будет наклейка на сетке. Улучшать имеет смысл так:

1. Те же пиксельные герои, но чище (новый sheet 4 направления)
2. Портреты — уже масло, их можно менять по одному
3. Не тащить 3D и фото в тайл-мир

Онлайн потом: не смешивать сеть в `engine.ts` сразу. Сначала вынести симуляцию (HP, инвентарь, участки) в чистое состояние — JSON уже для этого.
